# @amlplugins/google-firebase-admin

Native `firebase-admin` SDK re-exported under the `@amlplugins` namespace.

> Firebase Admin SDK (server).

## Install

```bash
npm install @amlplugins/google-firebase-admin
```

## Use

```ts
import { /* named exports from firebase-admin */ } from "@amlplugins/google-firebase-admin";
// or
import sdk from "@amlplugins/google-firebase-admin";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
